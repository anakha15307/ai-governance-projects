# Code of conduct

This repo is my public learning space. I want it to stay welcoming.

## Expectations

- Be kind and assume good faith.
- Critique the work, not the person. "This baseline is flawed because..."
  is useful; "you clearly don't understand..." is not.
- Do not post anyone's personal data, credentials, or private
  communications in issues or pull requests.

## Enforcement

I maintain this repo alone. Behavior that is harassing, hateful, or
otherwise hostile will get a warning first and a ban from interacting with
the repo if it continues. Decisions are mine and final.

## Scope

This applies to issues, pull requests, and any discussion attached to this
repo.

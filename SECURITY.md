# Security policy

## Scope

This repo contains portfolio demos and documents. There is no deployed
service, no user data, and no production system to attack. The policy
monitor, model registry, and dashboard are demonstration builds, not
hardened software.

## Reporting a vulnerability

If you find a genuine security issue (for example, a demo that leaks
credentials, or example code that is unsafe to copy), please open a GitHub
issue titled "Security: ..." describing it. I will respond within a week
and fix or remove the offending material.

Please do not submit real credentials, personal data, or exploit code in
issues.

## What this policy does not cover

I cannot provide security support for anyone else's deployment of these
demos. If you adapt this code for real use, you own its security review.
